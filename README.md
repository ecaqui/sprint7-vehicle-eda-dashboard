# sprint7-vehicle-eda-dashboard
EDA dashboard for vehicle listings with interactive visualizations built in Streamlit.

# 🚗 Vehicle Data Analysis Dashboard

## 📌 Descripción del proyecto

Este proyecto es una aplicación web desarrollada con Streamlit que permite analizar un conjunto de datos de vehículos usados. La aplicación realiza un análisis exploratorio de datos (EDA) y visualiza información clave mediante gráficos interactivos.

---

## 🎯 Objetivo

El objetivo del proyecto es facilitar la exploración de datos de anuncios de venta de coches, permitiendo identificar patrones relacionados con el odómetro, precios y otras variables relevantes.

---

## 🧰 Funcionalidades

- Carga de dataset de vehículos usados
- Visualización de estadísticas descriptivas
- Creación de histogramas interactivos
- Interfaz web simple e intuitiva
- Análisis exploratorio de datos (EDA)

---

## 📊 Tecnologías utilizadas

- Python
- Pandas
- Plotly
- Streamlit

---

## 🚀 Cómo ejecutar la aplicación

1. Activar el entorno:

```bash
conda activate sprint7_env
```
2. Ejecutar la app:
   
```bash
streamlit run app.py
```
